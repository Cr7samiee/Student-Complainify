# 🤖 AI-Based Student Complaint Analysis & Management System

> **AI-Based Student Complaint Analysis & Management System** is a Flask-based web application that uses NLP and a Multinomial Naive Bayes classifier (implemented from scratch) to classify complaints, predict priority, perform VADER sentiment analysis, manage complaints, send email notifications, and provide an admin analytics dashboard.

---

## 📌 Overview

The AI-Based Student Complaint Analysis & Management System is designed to simplify and improve the complaint handling process in educational institutions. Students can submit complaints (including anonymous submissions), track their status, and receive email notifications, while administrators can efficiently manage complaints through an interactive dashboard with AI-powered insights.

The system automatically classifies complaints into appropriate categories, predicts their priority, and analyzes sentiment using Natural Language Processing (NLP). The Multinomial Naive Bayes classifier is implemented entirely from scratch for educational purposes, demonstrating the complete machine learning workflow without relying on Scikit-learn.
